Deploy

Run it anywhere

One image carries the API, this website, and the fine-tuned model. It runs on a laptop, a single VM, or Kubernetes, on CPU or GPU. The model is baked in and the container runs offline as a non-root user.

Container

Build and run

docker build -f regmap_engine/docker/Dockerfile \
  -t regmap-engine:0.2 .          # from the repo root

docker run --rm -p 8000:8000 regmap-engine:0.2
#   UI   http://localhost:8000/
#   API  http://localhost:8000/docs

CPU-only or pinned CUDA

# slim CPU image
--build-arg \
  TORCH_INDEX=https://download.pytorch.org/whl/cpu

# pinned CUDA build
--build-arg \
  TORCH_INDEX=https://download.pytorch.org/whl/cu121

The default image is GPU-capable and also runs on CPU. Without the model present the service still answers on TF-IDF.

Kubernetes

Apply the manifests

kubectl apply -k regmap_engine/k8s

kubectl -n regmap port-forward \
  svc/regmap-engine 8010:80

Deployment · Service · HPA · NetworkPolicy, as a kustomization. The image reference is digest-pinned.

Optional tiers

GPU — an opt-in Deployment for a GPU node pool.
KEDA — scale-to-zero so an idle GPU costs nothing.

Both manifests exist but are untested: they need real GPU hardware, which the current environment does not have.

Configuration

VariableDefaultWhat it does
REGMAP_MODEL../models/regmap-embedder Embedder to load. If it fails, the engine degrades to TF-IDF rather than refusing to start.
REGMAP_DEVICEauto Force cpu or cuda. Auto-selects CUDA when visible.
REGMAP_LICENSED(empty) Comma-separated framework ids the operator holds a licence for. Default-deny: licensed frameworks are refused with 403 until listed here.
REGMAP_GPU_CU_MULT8 GPU-second to CPU-second ratio for the compute meter.
REGMAP_ENGINE_VERSION0.2 Stamped onto every response for reproducibility.

Before this is a paid service

The engine is deployable today, but it is not yet a billable multi-tenant service. Being straight about the gap:

No authentication

Every endpoint is open to whoever can reach the port. API keys are the next piece of work.

The meter is not invoiceable

Compute Units are recorded per request, but with no account attached, in memory, and per replica — so they are diagnostics, not billing.

No quotas

Nothing can reject a request or count it against a monthly allowance yet.

Prove you can do the job

RegMap University is the hands-on learning hub. The first graded lab is below; reading briefs, video tutorials, and real-world build labs are coming. Start with Map the control.

You are given a control from one framework and a set of candidate provisions from another. Select the ones that genuinely map. Your answer is scored against the official published crosswalk, not against an opinion, so this is the same judgement an auditor is paid to make.

Selecting everything will fail you. Scoring uses precision and recall, so over-selecting is penalised exactly as much as missing. That is deliberate: an auditor who maps a control to everything has done no work.
